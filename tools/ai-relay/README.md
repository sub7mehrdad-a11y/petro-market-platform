# رله‌ی هوش مصنوعی (Cloudflare Workers)

## چرا لازم است
سرور لیارا در ایران است. گوگل درخواست مستقیم از ایران را رد می‌کند («Gemini 400: User location is not supported») و Groq هم ۴۰۳ می‌دهد.
بنابراین «پرسش از مغز»، «پاسخ هوشمند» و ثبت پیش‌بینی مغز روی سایت زنده کار نمی‌کنند. ربات‌های روزانه (GitHub Actions، خارج از ایران) مشکلی ندارند.

این Worker بیرون از ایران اجرا می‌شود و فقط دو مسیر را به گوگل و Groq می‌رساند. رایگان است (سقف روزانه‌ی ۱۰۰ هزار درخواست).

## راه‌اندازی (حدود ۵ دقیقه)
1. در dash.cloudflare.com وارد شوید (حساب رایگان کافی است) ← **Workers & Pages** ← **Create** ← **Create Worker** ← نام مثلاً `sepehran-ai-relay` ← **Deploy**.
2. **Edit code** را بزنید، همه‌ی کد پیش‌فرض را پاک کنید و محتوای فایل `worker.js` همین پوشه را بچسبانید ← **Deploy**.
3. همان Worker ← **Settings** ← **Variables and Secrets** ← **Add** ← نوع **Secret**، نام `RELAY_TOKEN`، مقدار یک رشته‌ی تصادفی بلند (مثلاً ۴۰ حرف) ← **Deploy**.
4. آدرس Worker را بردارید (مثل `https://sepehran-ai-relay.<نام-شما>.workers.dev`).
5. در لیارا (تنظیمات برنامه ← متغیرهای محیطی) دو متغیر اضافه و برنامه را دوباره راه‌اندازی کنید:
   - `AI_RELAY_URL` = آدرس Worker (بدون «/» آخر)
   - `AI_RELAY_TOKEN` = همان مقدار `RELAY_TOKEN`

بدون این دو متغیر همه‌چیز مثل قبل (اتصال مستقیم یا `HTTPS_PROXY`) کار می‌کند.

## اگر هنوز خطای «location» آمد
Cloudflare از نزدیک‌ترین مرکز داده به کاربر درخواست را اجرا می‌کند و بعضی مرکزها از دید گوگل «منطقه‌ی پشتیبانی‌نشده» حساب می‌شوند. اگر بعد از راه‌اندازی باز هم همان خطا را دیدید:
- در Worker ← **Settings** ← **Placement** ← **Smart** را امتحان کنید؛ یا
- به‌جای Cloudflare، یک پراکسی HTTP بیرون از ایران بگیرید و در لیارا `HTTPS_PROXY` را به آن بدهید (کد از قبل پشتیبانی می‌کند).

## امنیت
- بدون هدر `x-relay-token` درست، Worker ۴۰۳ می‌دهد؛ فقط دو مسیر ثابت مجاز است؛ هیچ کلیدی روی Worker ذخیره نمی‌شود.
- رمز را در گیت یا چت نگذارید.
